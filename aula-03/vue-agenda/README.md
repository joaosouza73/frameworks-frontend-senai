# Ritmo — Vue

Versão Vue da agenda acadêmica da Aula 03. A interface usa Single-File Components, Composition API, propriedades computadas e eventos entre componentes.

## Executar

Requer Node.js e npm.

```bash
npm install
npm run dev
```

Para validar o pacote de produção, execute `npm run build`.

## Dados

As atividades ficam no `localStorage` deste navegador, na chave `ritmo-agenda-vue-v1`. Elas não são enviadas para uma API nem sincronizadas entre dispositivos.
