# Ritmo — Next.js

Versão Next.js da agenda acadêmica da Aula 03. Usa App Router, layout com metadados e componentes React no cliente para interagir com o `localStorage`.

## Executar

Requer Node.js e npm.

```bash
npm install
npm run dev
```

Para validar o pacote de produção, execute `npm run build` e depois `npm start`.

## Dados

As atividades ficam no `localStorage` deste navegador, na chave `ritmo-agenda-next-v1`. Elas não são enviadas para uma API nem sincronizadas entre dispositivos.
