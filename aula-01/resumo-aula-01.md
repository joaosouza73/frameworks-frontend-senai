# Resumo da Aula 01 — Frameworks Front-end

## Introdução

A Aula 01 da disciplina de Frameworks Front-end teve como objetivo apresentar conceitos iniciais relacionados ao desenvolvimento de aplicações Web e preparar o ambiente para as atividades práticas que serão desenvolvidas ao longo do semestre.

Durante a aula, foram abordados conceitos relacionados ao desenvolvimento Front-end, à utilização de ambientes de desenvolvimento, ao GitHub e ao processo de publicação de aplicações Web.

## Atividade 01 — Repositório no GitHub

Como primeira atividade, foi criado um repositório no GitHub para centralizar e organizar as atividades desenvolvidas durante a disciplina de Frameworks Front-end.

O repositório será utilizado ao longo do semestre para armazenar os projetos, documentos e demais atividades realizadas nas aulas.

Também foi criado um arquivo `README.md`, responsável por apresentar e organizar as informações gerais do projeto.

## Atividade 02 — Projeto em Vanilla JavaScript

Foi desenvolvido um projeto utilizando **Vanilla JavaScript**, juntamente com as linguagens HTML e CSS.

Vanilla JavaScript é a utilização do JavaScript sem a necessidade de frameworks ou bibliotecas externas. Dessa forma, o projeto permite compreender os fundamentos da linguagem e sua integração com HTML e CSS.

Para a atividade, foi desenvolvido um sistema de **Controle Financeiro**, permitindo cadastrar movimentações financeiras e acompanhar informações como:

* saldo atual;
* entradas;
* saídas;
* descrição das movimentações;
* valores das movimentações;
* exclusão de registros.

### HTML

O HTML foi utilizado para construir a estrutura da aplicação, incluindo:

* título e cabeçalho;
* cartões de resumo financeiro;
* formulário para cadastro das movimentações;
* campos de descrição, valor e tipo da movimentação;
* lista de transações;
* elementos de interação com o usuário.

### CSS

O CSS foi utilizado para definir a aparência e organização visual da aplicação.

Foram aplicados estilos para:

* organização dos elementos;
* cores;
* espaçamentos;
* fontes;
* cartões;
* formulários;
* botões;
* lista de transações;
* responsividade da página.

### JavaScript

O JavaScript foi responsável por implementar a lógica e a interatividade do sistema.

Entre as funcionalidades desenvolvidas estão:

* cadastro de novas transações;
* validação dos dados inseridos;
* identificação de entradas e saídas;
* cálculo do saldo;
* atualização dos valores apresentados na tela;
* exibição das transações;
* exclusão de transações;
* formatação dos valores monetários.

## Ambiente de Desenvolvimento

Para o desenvolvimento do projeto foi utilizado um **IDE (Integrated Development Environment)**, que permite escrever, organizar e editar os arquivos necessários para a aplicação.

O projeto foi desenvolvido utilizando arquivos separados para HTML, CSS e JavaScript, facilitando a organização e manutenção do código.

## Git e GitHub

Durante a atividade também foi realizada a integração do projeto com o Git e o GitHub.

O **Git** foi utilizado para realizar o controle de versões do projeto, permitindo registrar as alterações realizadas durante o desenvolvimento.

O **GitHub** foi utilizado para armazenar o código-fonte de forma remota e possibilitar o acompanhamento e organização das atividades da disciplina.

O projeto foi conectado ao repositório remoto e enviado para a branch `main`.

## Deploy da Aplicação

Após o desenvolvimento do projeto e sua publicação no GitHub, foi realizado o **deploy da aplicação utilizando a Vercel**.

O deploy permite disponibilizar a aplicação na Internet, tornando possível acessar o projeto por meio de um navegador.

### Aplicação publicada

A aplicação desenvolvida na Aula 01 está disponível em:

**https://frameworks-frontend-joao.vercel.app**

## Conclusão

A Aula 01 proporcionou uma introdução prática ao desenvolvimento Front-end, envolvendo desde a criação de um projeto utilizando HTML, CSS e Vanilla JavaScript até o versionamento do código com Git e GitHub e a publicação da aplicação por meio da Vercel.

A atividade permitiu compreender o fluxo básico de desenvolvimento de uma aplicação Web, desde sua criação e organização dos arquivos até sua disponibilização online.
