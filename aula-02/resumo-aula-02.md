# Resumo da Aula 02 — React

## Introdução

A Aula 02 da disciplina de Frameworks Front-end teve como foco o desenvolvimento de uma aplicação utilizando **React**, além da utilização de ferramentas de versionamento e publicação de aplicações Web.

Durante a atividade, foi desenvolvido um **Jogo da Velha**, utilizando React e Vite como base para o projeto. Também foram trabalhados o Git, GitHub e Vercel para versionamento, armazenamento e publicação da aplicação.

## Atividade 1 — Desenvolvimento da Aplicação React

A primeira atividade consistiu no desenvolvimento de uma aplicação utilizando **React** e o **Visual Studio Code (VS Code)** como ambiente de desenvolvimento.

Para iniciar o projeto, foi utilizado o **Vite**, uma ferramenta utilizada para criar e executar projetos Front-end modernos.

O projeto desenvolvido foi um **Jogo da Velha**, com uma interface interativa e funcionalidades implementadas utilizando os recursos do React.

### Funcionalidades desenvolvidas

A aplicação possui:

* tabuleiro de 3x3;
* jogadores X e O;
* alternância automática entre os jogadores;
* identificação do vencedor;
* identificação de empate;
* botão para iniciar uma nova partida;
* contador de vitórias dos jogadores;
* botão para zerar o placar;
* interface responsiva para diferentes tamanhos de tela.

## React e Componentes

O React foi utilizado para construir a interface da aplicação e controlar seu comportamento.

A aplicação foi desenvolvida utilizando conceitos fundamentais do React, incluindo:

* componentes;
* estado;
* eventos;
* renderização dinâmica;
* atualização da interface conforme o estado da aplicação.

No projeto, o estado foi utilizado para armazenar as informações necessárias para controlar o tabuleiro, o jogador atual, o vencedor, o empate e o placar.

## Uso do `useState`

Um dos principais recursos utilizados no projeto foi o Hook `useState`.

O `useState` permite criar e atualizar valores de estado dentro de um componente React.

No Jogo da Velha, ele foi utilizado para controlar:

* o conteúdo de cada posição do tabuleiro;
* o jogador da vez;
* o vencedor da partida;
* o estado de empate;
* o placar de vitórias dos jogadores.

A utilização do estado permite que a interface seja atualizada automaticamente sempre que uma ação do usuário modifica as informações da aplicação.

## Ambiente de Desenvolvimento

O projeto foi desenvolvido utilizando o **Visual Studio Code (VS Code)** como ambiente de desenvolvimento.

O VS Code foi utilizado para:

* criação e edição dos arquivos;
* organização da estrutura do projeto;
* execução dos comandos pelo terminal;
* acompanhamento e desenvolvimento da aplicação.

O projeto também utilizou o **Vite** para criar e executar o ambiente de desenvolvimento do React.

## Git e GitHub

Depois do desenvolvimento da aplicação, foi utilizado o **Git** para realizar o versionamento do projeto.

Foram realizadas operações de:

* preparação dos arquivos;
* criação de commit;
* envio das alterações para o repositório remoto.

O **GitHub** foi utilizado para armazenar o código-fonte do projeto e manter a aplicação versionada.

O projeto foi adicionado ao repositório principal:

`frameworks-frontend-senai`

e enviado para a branch principal `main`.

## Deploy na Vercel

Após o envio do projeto para o GitHub, foi realizado o deploy da aplicação através da **Vercel**.

O repositório do GitHub foi conectado à Vercel, permitindo que a plataforma realizasse o processo de publicação do projeto.

A aplicação foi configurada para utilizar a pasta:

`aula-02/react`

como diretório principal do projeto.

Após a conclusão do deploy, o Jogo da Velha ficou disponível publicamente na Internet.

### Aplicação publicada

**URL:**
https://jogo-da-velha-react-one.vercel.app/

## Atividade 3 — Relatório Técnico sobre Framework Front-end

Além do desenvolvimento da aplicação React, a Aula 02 também inclui a elaboração de um **relatório técnico sobre um Framework Front-end**.

O relatório deverá apresentar:

* principais características do framework escolhido;
* vantagens de sua utilização;
* aplicações no mercado;
* exemplo de utilização em um projeto Web.

Para esta atividade, foi escolhido o **React**, relacionando a parte teórica ao projeto prático desenvolvido durante a aula.

O relatório será disponibilizado no repositório juntamente com as demais atividades da Aula 02.

## Resultados Obtidos

Ao final da Aula 02, foi desenvolvida uma aplicação funcional utilizando React, com recursos de interação e gerenciamento de estado.

Também foi concluído o processo de versionamento do projeto utilizando Git e GitHub e realizada sua publicação na Vercel.

A atividade permitiu compreender na prática o funcionamento básico de uma aplicação React e o fluxo de desenvolvimento, versionamento e deploy de um projeto Front-end.

## Conclusão

A Aula 02 proporcionou uma experiência prática com o desenvolvimento utilizando React. A criação do Jogo da Velha permitiu aplicar conceitos importantes, como componentes, estados, eventos e atualização dinâmica da interface.

Além da programação, a atividade também reforçou o uso de Git e GitHub para controle de versões e da Vercel para publicação da aplicação.

Dessa forma, a aula contribuiu para a compreensão do processo completo de desenvolvimento de uma aplicação Front-end utilizando um framework moderno.
